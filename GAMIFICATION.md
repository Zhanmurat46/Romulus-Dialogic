---

# 0. ПРИНЦИП

Геймификация здесь — **не награды, а давление и последствия**.

Студент должен чувствовать, что перед ним живой раздражённый человек, у которого заканчивается терпение, а не форма для ввода текста. Кубки и звёздочки этого не дают, шкала терпения — даёт.

**Что берём:** напряжение в реальном времени, видимые последствия своих слов, рост между попытками.
**Что не берём:** очки за клики, ежедневные серии, мультяшные иконки, случайные награды.

**Про стиль иконок отдельно.** Не использовать наборы с кубками, джойстиками, коронами и медалями в плоском мультяшном стиле. Причины: это самый узнаваемый сток, он конфликтует со сдержанным визуальным языком продукта и читается жюри как шаблон. Вся графика рисуется inline SVG в палитре продукта — геометрия, а не персонажи.

# 1. ШКАЛА ТЕРПЕНИЯ ГОСТЯ — ядро механики

Главный элемент. Видна в шапке диалога постоянно.

### 1.1 Как выглядит

- Горизонтальная шкала 120×8px в шапке рядом с подписью «Терпение гостя».
- Заливка меняет цвет по уровню: **60–100%** — `--accent-3` (зелёный), **30–59%** — `--accent-2` (терракота), **0–29%** — `--fail`.
- Под шкалой подпись словом, меняется вместе с уровнем: «Спокоен» → «Раздражён» → «На грани» → «Готов уйти».
- Изменение анимируется 400ms. При падении — короткий «толчок»: шкала дёргается на 3px и возвращается.

### 1.2 Как считается

Старт — **70**. Пересчёт после каждой реплики студента, **кодом, не моделью**:

| Событие | Δ |
|---|---|
| Ответил быстрее 20 сек | +3 |
| Пауза 20–45 сек | 0 |
| Не уложился в таймер | −12 |
| Реплика короче 15 символов | −8 |
| В реплике есть извинение (словарь: «извин», «прошу прощения», «сожалею») | +10 |
| Задан вопрос (есть «?») | +6 |
| Есть конкретика (цифры, «номер», «HTL», категория) | +8 |
| Слова-отговорки («система», «не моя вина», «так бывает», «обычно») | −10 |
| Базовое затухание каждой реплики | −4 |

Ограничение 0–100. Словари — простые массивы строк в начале скрипта, регистр не важен.

**Почему кодом:** мгновенно, бесплатно, детерминированно, не ломается при сбое API. Модель занята ролью, а не подсчётом.

### 1.3 Как влияет на игру

- **Терпение ≤ 25** → в системный промпт роли добавляется строка: «Гость на грани ухода. Отвечай резко, одной фразой, пригрози уйти к менеджеру». Модель начинает вести себя жёстче — это видно и ощутимо.
- **Терпение = 0** → диалог обрывается. Гость уходит. Экран результата открывается со строкой: **«Гость ушёл на 5-й реплике»**. Оценка проводится по тому, что успели.
- **Терпение ≥ 85 в конце** → значок «Удержал клиента».

Обрыв диалога — не наказание ради наказания. Это и есть реальное последствие, которого нет ни в одном чате.

# 2. ТАЙМЕР ОТВЕТА

### 2.1 Поведение

- **45 секунд** на реплику. Отсчёт стартует, когда пришёл ответ гостя.
- Визуал: **тонкое кольцо** вокруг кнопки «Отправить», обводка убывает через `stroke-dashoffset`. Никаких крупных цифр — они создают экзаменационную тревогу, а не рабочее напряжение.
- Последние 10 секунд: кольцо становится `--fail`, появляется счётчик цифрами.
- **Время вышло** → реплика студента не отправляется, вместо неё уходит служебная реплика `[пауза: администратор молчит]`, терпение −12, гость реагирует на молчание.

### 2.2 Почему именно так

Жёсткий провал «не успел — проиграл» ломает главное: продукт должен собирать материал для оценки. Молчание как ход **реалистичнее** — на стойке пауза тоже читается как неуверенность, и гость на неё реагирует.

### 2.3 Обязательный переключатель

На экране сценария — чекбокс **«Режим с таймером»**, по умолчанию включён.

Выключенный таймер нужен для двух вещей: первый прогон студента, который знакомится с интерфейсом, и **демо на сцене**, где вы не хотите, чтобы время вышло посреди объяснения жюри.

# 3. РАНГИ

Мотивация повторного прохождения без детского оформления. Ранг считается по **лучшему результату** из localStorage.

| Результат | Ранг |
|---|---|
| 0–3 из 8 | Стажёр |
| 4–5 | Администратор |
| 6–7 | Старший администратор |
| 8 из 8 при терпении ≥ 70 | Наставник смены |

- Показывается на главной под кнопками: «Ваш ранг: Администратор» и мелко «До следующего: наберите 6 из 8».
- На экране результата — если ранг вырос, плашка `--brand-soft`: «Новый ранг: Старший администратор».
- Оформление — **текстом на плашке**, без медалей и лент.

# 4. ЗНАЧКИ

Ровно **пять**. Больше — обесценивание.

| Значок | Условие | Форма SVG |
|---|---|---|
| Спокойный тон | Ни одной отговорки за диалог | Круг |
| Удержал клиента | Терпение в конце ≥ 85 | Круг с точкой в центре |
| Чистая работа | 8 из 8 | Шестиугольник |
| Быстрая реакция | Все ответы быстрее 25 сек | Ромб |
| Рост | Результат выше прошлой попытки | Треугольник вершиной вверх |

**Оформление:** геометрическая фигура 40×40, обводка 2px, без заливки. Полученный — цветом компетенции, неполученный — `--track`, приглушённый. Подпись 11px под фигурой.

Ряд из пяти фигур на экране результата под графиком компетенций. Полученный значок появляется с масштабированием 0.8→1 за 250ms, с задержкой 100ms между ними.

# 6. ЧЕГО НЕ ДЕЛАТЬ

| Не добавлять | Почему |
|---|---|
| Очки, монеты, уровни с XP | Отвлекают от профессионального смысла, выглядят как мобильная игра |
| Ежедневные серии, напоминания | Нет ретеншна у продукта, который проходят 2–3 раза |
| Звуки | На демо со сцены это риск и раздражитель |
| Таблицу лидеров | Нужна БД, запрещена разделом 3.10 основного плана |
| Мультяшные иконки из стоковых наборов | Конфликт со стилем, минус за шаблонность |
| Конфетти, анимацию победы | Обесценивает разбор ошибок, который и есть суть продукта |

# 7. ЧТО ПРОВЕРИТЬ

- [ ] Шкала терпения заметно падает после грубой или пустой реплики
- [ ] При терпении ≤ 25 гость **ощутимо** меняет тон
- [ ] При нуле диалог обрывается, результат всё равно считается
- [ ] Таймер истекает → уходит `[пауза]`, гость на неё реагирует
- [ ] Чекбокс «Режим с таймером» реально отключает таймер
- [ ] Ранг сохраняется между сессиями
- [ ] Значки не сбивают вёрстку при любом наборе
- [ ] **Ни одной растровой иконки в проекте**

# 8. ЗАЧЕМ ЭТО В ПИТЧЕ

Механика терпения — **ответ на главный вопрос жюри «чем это лучше ChatGPT»**.

Формулировка: «В чате собеседник бесконечно терпелив. На стойке — нет. У нашего гостя терпение заканчивается от пауз, отговорок и общих фраз — и студент видит это в реальном времени. Сорвать разговор здесь можно, и это единственное место, где это безопасно».

Дополнительный аргумент по критерию «Валидация»: терпение — вторая измеримая метрика помимо чек-листа. Две метрики на одном прогоне вместо одной.
