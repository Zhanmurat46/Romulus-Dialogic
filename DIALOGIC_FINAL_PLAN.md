## 2. Разбор текущего MVP

**Сильное — не трогать:**

- Ядро верное: ценность не в чате, а в **разборе с дословными цитатами** + `quoteFound()` + флаг `fabricated`. Это структурный ответ на вопрос «чем лучше ChatGPT».
- Шкала терпения, уход собеседника при 0, обратные пункты (`noblame`, `nodiagnosis`), профиль компетенций, график динамики — это уже симулятор, а не обёртка над чатом.
- Технически: serverless-прокси, ключ на сервере, перебор моделей, три уровня парсинга JSON, demo-режим без сети, `prefers-reduced-motion`.
- TEST PLAN пройден на живой модели, 12 пунктов.

### Что сохраняется из запретов, несмотря на смену домена

**Ключи `localStorage` НЕ переименовывать** (`praxis.sessions.hotel`, `praxis.sessions.clinic`, `praxis.scenario`). Внутри — накопленные прогоны, то есть ваши данные валидации и график динамики. Переименование продукта на них не распространяется. Это техническая деталь, которой жюри не видит.

**Про домен.** Безопасный порядок: сначала добавить новый домен алиасом и убедиться, что он открывается, и только потом переименовывать проект. Так у вас ни секунды не будет нерабочей ссылки. Порядок расписан в промпте 2.

**`ACCESS_CODE`** станет публичным вместе с репозиторием. За оставшиеся часы риск невелик — поменяйте код после хакатона (константа в `index.html` + переменная на Vercel, менять вместе).

## 4. Визуальный аудит и дизайн-направление

Я разобрал реальный CSS сайта (19,8 КБ). Проблема не в том, что мало украшений, а в том, что **все элементы страницы имеют один вес.**

| Что именно | Почему читается как «неоформленный документ» |
|---|---|
| **Системный шрифт** `-apple-system, Segoe UI, Roboto` | Главная причина. На Windows-ноутбуке жюри это буквально шрифт по умолчанию. Считывается за 0,3 секунды |
| Плоская шкала: h1 38 → h2 18 → текст 16 | Ни одного крупного акцента. У современных продуктов hero 56–72px |
| Одна ширина 760px на всю страницу, при этом шапка 1040px | Ни узких, ни широких блоков, ни асимметрии, плюс рассогласование |
| Одна глубина: все карточки `1px #E0DACE` + `shadow 0 1px 2px .04` | Ничто не приподнято, ничто не утоплено |
| Цвет только как статус | `--brand` живёт на кнопках и цитатах; `--accent-2/3/4` только в графиках. На странице нет ни одного цветного поля |
| Ни одной иконки на лендинге | При этом **5 SVG-значков уже нарисованы** — словарь есть, наверху не используется |
| Точечная фактура .06 | Невидима, не даёт ничего |
| Hover кнопки `opacity: .9` | Самый дешёвый на вид ховер из возможных |
| Блок `.cmp` (сравнение с ИИ-чатом) | Лучший смысловой блок страницы выглядит как две серые коробки |

### Направление

Концепцию **«рабочий журнал практики, а не AI-чат»** сохраняем — она правильная, кейс прямо говорит, что наличие AI баллов не даёт. Но поднимаем её с уровня «простой документ» до уровня **«редакционный инструмент / клинический разбор»**.

Референсы как паттерны, не для копирования: **Linear** — спокойная плотность, типографика как главная иерархия; **Brilliant / Duolingo** — момент награды в обучении; редакционные лендинги с серифными заголовками; **отчёты-дебрифы авиа- и медсимуляторов** — ваш экран результата по сути и есть дебриф, это надо подчеркнуть.

### Токены — передать Claude Code как есть

**Шрифты — самохостинг, без CDN.** Скачать `.woff2` (latin + cyrillic, веса 400/600/700) в `/fonts/` и подключить через `@font-face` + `font-display: swap`. Системный стек оставить фолбэком в том же правиле. Требование «без Google Fonts CDN» выполняется: файлы лежат в проекте.

```
Заголовки:  Literata   (сериф, кириллица, «методическое/редакционное»)
Интерфейс:  Inter      (кириллица, нейтральный гротеск)
```
Без серифа: `Manrope` заголовки + `Inter` текст.

```css
/* добавить в :root, старые токены не менять */
--ink-deep:    #14333E;   /* тёмная полоса и подвал — единственное цветное поле */
--brand-hover: #1A4351;
--paper-2:     #E9E3D7;
--shadow-1: 0 1px 2px rgba(20,51,62,.05);
--shadow-2: 0 4px 16px -4px rgba(20,51,62,.10);
--shadow-3: 0 12px 32px -8px rgba(20,51,62,.16);
--r-sm: 10px; --r-md: 14px; --r-lg: 20px;
```

```

block-title  30 / 1.2  / -0.015em
h2           20
текст        16–17 / 1.55
caption      13
eyebrow      12 / .10em / uppercase
числа результата  48–64, tabular-nums
```

1. **Репозиторий + README.** Это не улучшение, а **невыполненное требование сдачи**. Лучшее соотношение эффекта ко времени во всём плане.
2. **Дизайн 3A + 3B.** Прямые 15 баллов плюс ореол на «Презентацию». Ваш продукт сейчас **недооценён собственным интерфейсом**: ядро сильнее, чем выглядит.
3. **Реальные прогоны студентов.** 20 баллов «Исследование» стоят на этом, и это ноль вашего кода.
4. **Доступность + телефон.** Дёшево, и это то, что **называется вслух на защите**: клавиатурный проход, `aria-live` на ленте диалога, `prefers-reduced-motion`, контраст не ниже 4.5:1. Жюри такое слышит редко.
5. **Третий сценарий.** Снимает главный вопрос о масштабируемости не словами, а показом: три специальности на одном движке.

### Что может сломать демо

| Риск | Вероятность | Парашют |
|---|---|---|
| **Квота Gemini / 429 на сцене** | средняя | Demo-режим. **Отрепетируйте переход на него за 3 секунды** — это главный парашют |
| **Wi-Fi площадки** | средняя | Хот-спот + Demo-режим + **записанное видео прогона на 60 секунд** |
| **Смена домена перед сдачей** | средняя | Порядок в промпте 2: сначала алиас, проверка, потом переименование. **Обновить ссылку и QR в презентации сразу после**, а не в конце |
| **Голосовой ввод: запрос микрофона на сцене** | **высокая** | Не включать голос в демо вообще. Показать одним касанием, если спросят, и вернуться к печати |
| **Озвучка звучит роботом** | средняя | Выключено по умолчанию. Если голос ОС плохой — не показывать совсем: это бьёт по позиционированию «не обёртка над GPT» |
| **Третий сценарий врёт в оценке** | **высокая без проверки** | Два обязательных живых прогона в промпте 6. Не прошли — откатить сценарий целиком |
| **Правка CSS ломает высоту экрана диалога** | средняя | Запрет в промптах 3A/3B. Проверять на 1280×720 — типичное разрешение проектора |
| **Шрифты не загрузились** | низкая | `font-display: swap` + системный фолбэк в том же правиле |
| **Переименование стёрло localStorage** | средняя, если проигнорировать | Явный запрет в промпте 2. Проверка: график динамики после переименования |

### Что останется слабым

- **Исследование.** 6–10 прогонов — мало, слепого сравнения с оценкой преподавателя не будет. **Не завышайте цифры**: кейс прямо запрещает выдавать предполагаемое за реальное. «N = 8, метод такой-то, вот что увидели» звучит сильнее выдумки и не разваливается на вопросах.
- **Нет кабинета преподавателя** — только CSV и кнопка копирования разбора. Ответ готовьте заранее: «две недели, Postgres плюс аккаунт преподавателя; CSV — осознанный объём MVP».
- **Оценка опирается на суждение одной модели.** Вопрос прилетит обязательно. Ответ у вас сильный и уже в коде: **сверка цитаты с расшифровкой и флаг `fabricated`** — модель не может похвалить за то, чего не было в тексте. Отрепетируйте эту фразу дословно.
- **Голос — тонкий слой.** Если спросят «а зачем он», честный ответ: снижает барьер для устной практики, но ядро продукта не в нём.

### Чего точно не делать

- ❌ Несколько клиентов одновременно.
- ❌ Четвёртый и последующие сценарии.
- ❌ Внешний TTS-API.
- ❌ Переименовывать ключи `localStorage`.
- ❌ React, сборка, рефакторинг, база данных, авторизация, кабинет преподавателя.
- ❌ Тёмная тема и «AI-эстетика».
- ❌ Любой код после 4:05.
- ❌ Ставить на сайт цифры, которых у вас нет.
